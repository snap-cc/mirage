how to use:
1) make sure that accelerated hardware rendering is off in windows settings 
(System > Display > Graphics > Change default graphics settings > Hardware-accelerated GPU scheduling)

2) launch cs2
3) run hack & enjoy

----------------------------------------------------------------

known issues:
1) rcs standalone don't work properly when u shoot not at player on community servers
(for some reason, on local server everything works perfect)
2) remove flashbang effects works only when u alive
3) keybinds states in 'toggle' mode reset when game window loses focus
4) triggerbot doesnt work when target is far away
